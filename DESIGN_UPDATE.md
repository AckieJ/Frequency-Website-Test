# Orange and graphite refresh

- Changed the dark purple/lime theme to charcoal, warm gray and vivid orange.
- Made the hero heading legible with a standard Inter/system sans serif, reduced letter compression, normal line spacing and smaller responsive sizing.
- Updated both the inline CSS include and standalone CSS file so they stay synchronized.
- Updated the favicon and theme-color.

## Preview with Jekyll

```sh
bundle install
bundle exec jekyll serve --baseurl ""
```

Visit http://localhost:4000/

If publishing to a GitHub Pages project repository, preserve the appropriate `_config.yml` baseurl for the deployed path.
