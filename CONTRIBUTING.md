# Contributing

Anyone in The Frequency can update the website. You do not need to know how to code.

1. Read [docs/EDITING.md](docs/EDITING.md). It covers every common task step by step.
2. Edit the file on GitHub and click **Commit changes**.
3. Wait about a minute, then refresh the site.

Not comfortable editing? Open an [issue](../../issues/new/choose) using **Request a website change** and someone will take care of it.

## Ground rules

- Only edit files in `_data/` and `assets/images/` unless you know what you are doing.
- Resize photos before uploading (under 2000 pixels wide is plenty).
- Get permission before posting someone's photo, name, or fun fact.
- If a change goes wrong, you can always undo it: see "Undo a mistake" in the editing guide.
